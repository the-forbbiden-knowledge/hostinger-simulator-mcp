PROJETO EM DESTAQUE

O projeto

HOSTINGER · SIMULAÇÃO LOCAL

Hostinger Simulator MCP

Protótipo independente de infraestrutura e colaboração, construído para visualizar serviços, analisar políticas de acesso e experimentar cenários de forma determinística — sem controlar uma conta real da Hostinger.

C++20WindowsElixir / OTPWebView2MCP planejado
Ver projeto no GitHub ↗
ARQUITETURA

Motor nativo, interface local.

O motor C++20 fornece respostas sintéticas testáveis. O cliente Windows WebView2 apresenta essas respostas em modo de leitura. A ponte Elixir/OTP está no repositório; a integração MCP e a operação real de provedores ainda não estão implementadas.

◇

Infraestrutura

Cenários locais para VPS, DNS, websites e estados de serviços, sem provisionamento ou requisições ao provedor.

⌘

Colaboração

Políticas hipotéticas para e-mail, suporte, continuidade e responsabilidades entre planos de serviço.

▣

Verificação

Contratos de segurança, testes automatizados e limites explícitos antes de qualquer integração futura.

Limite operacional

Este website é uma apresentação estática. O aplicativo Windows atual é um visualizador de simulações offline. Não há login, IA conectada, SSH, execução de comandos, gestão de contas Hostinger ou serviços reais neste site público.
